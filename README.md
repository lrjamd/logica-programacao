# logica-programacao
Curso de Lógica de Programação em Python

## Cálculadora - código Python
O código Python presente neste repositório implementa uma calculadora que realiza operações matemáticas essenciais, incluindo soma, subtração, multiplicação e divisão. Ele fornece uma maneira simples e eficiente de executar cálculos diretamente no ambiente de programação, tornando-se uma ferramenta útil para diversas aplicações

## Como executar o arquivo .sh
Para executar um arquivo .sh, primeiro é necessário garantir que ele tenha permissão de execução. Isso pode ser feito com o comando chmod +x nome_do_arquivo.sh. Depois, basta rodá-lo no terminal usando ./nome_do_arquivo.sh.
